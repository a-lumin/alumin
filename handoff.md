2. Use Site 1: Stripe as a visual reference for its strong hero area, bold typography, clean spacing, and clear content hierarchy.

   - H1: 72px desktop, 48px tablet, 36px mobile

9. Set body text sizes:
   - Body: 18px desktop, 16px mobile

    - 1.1 for headings
    - 1.5 for body text

11. Use the color palette exactly as follows:
    - Background: #1a1110
    - Text: #860111
    - Accent: #480607

12. Use the background color #1a1110 as the primary page background across the entire site.

13. Use the text color #860111 for all primary text, headings, labels, and navigation text.

14. Use the accent color #480607 for:
    - Links
    - Borders
    - Filled buttons
    - Hover states
    - Section dividers
    - Card backgrounds
    - Focus outlines

15. Keep overall contrast strong through scale, spacing, borders, and hierarchy while preserving the specified color palette.

16. Place my name at the top of the page inside the hero section.

17. Position the hero image at the very top of the page.

18. Make the hero image full width.

    - 50vh desktop

    - Max width: 1440px

    - Mobile: 0–767px

    - Laptop/Desktop: 1024px and above

    - 24px desktop

    - Border radius: 0px

    - Background: #480607

    - Minimum height: 64px
    - Padding: 16px 24px

    - Background changes to #860111
    - Text changes to #1a1110
    - Border changes to #860111

    - Duration: 200ms
    - Timing: ease-out

35. Maintain visible keyboard focus states using a 2px outline in the accent color.

36. Use the moving background on the entire page behind all content.

37. The moving background consists of black, red, and white shooting stars.

38. Animate shooting stars at a medium speed.

39. Shooting stars should travel diagonally across the screen.

40. Use approximately 20–30 active shooting stars at any time.

41. Vary shooting-star size between 1px and 4px.

42. Vary opacity between 0.3 and 1.0 to create depth.

43. Use animation durations between 4 and 8 seconds to maintain a medium perceived speed.

44. Ensure the shooting-star animation loops infinitely and smoothly.

45. Keep the animation decorative only and never allow it to interfere with readability or interaction.

46. Maintain generous negative space around all major sections.

47. Keep visual hierarchy driven primarily by typography size, spacing, and button groupings.

48. Avoid rounded shapes, glassmorphism, gradients, excessive shadows, and ornamental effects.

49. Prefer clean edges, flat fills, strong blocks of color, and simple geometric structure.

50. Every future build or edit of this homepage must preserve all rules above unless explicitly instructed to change them.
